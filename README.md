# 格莉奇遊樂園・霓虹鋼珠台

一款可獨立遊玩的格莉奇鋼珠台。鋼珠具有重力、牆面反彈、角色碰撞柱與左右擋板碰撞；每局三顆球，分數和最高分保存在瀏覽器裡。

## 操作

- 手機：按住畫面下方的左右擋板，點「發射鋼珠」。
- 鍵盤：方向鍵左右或 `A`、`D` 控制擋板，空白鍵發射。
- 右上角聲音開關會同時控制主題曲與遊戲音效。

## 本機執行

```bash
python3 -m http.server 4173
```

瀏覽 `http://127.0.0.1:4173/`。角色碰撞柱共用單一頭像 Atlas，不載入七張獨立圖片，也不依賴外部 CDN。

日後嵌入 Larch 時，頁面會顯示「離開」按鈕，並把遊樂園主題曲交由外層統一播放。
